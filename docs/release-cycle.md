# Release Cycle

CyberRangeCZ follows a **quarterly release cycle**, with four planned releases per year.

Releases are planned for the **first week of the corresponding release month**. The exact release date may be adjusted depending on the status of the release and ongoing development work.

## Release Schedule

| Release | Planned timing          |
| ------- | ----------------------- |
| **.03** | First week of March     |
| **.06** | First week of June      |
| **.09** | First week of September |
| **.12** | First week of December  |

## Release Naming

Releases use the following naming convention:

`vYYYY.MM`

where:

* `YYYY` — release year
* `MM` — release month

For example, `v2027.03` represents the March release.

## Release Frequency

The planned release cadence is **quarterly**, with releases scheduled in:

**March → June → September → December**

This provides approximately three months between releases and allows time for feature development, testing, stabilization, and release preparation.
